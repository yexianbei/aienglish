# 使用指南

## 🎯 快速开始

### 用户端使用

#### 1. 在 ChatGPT 中安装 App

1. 打开 ChatGPT
2. 在 App Store 中搜索 "AI English Learning"
3. 点击安装
4. 授权必要的权限

#### 2. 添加生词

在 ChatGPT 聊天中翻译单词时：

```
你: "翻译 procrastinate"

ChatGPT: "procrastinate
拖延、耽搁 (v.)
音标: /prəˈkræstɪneɪt/

例句:
- Don't procrastinate, start your work now.
  不要拖延，现在就开始工作吧。"

[📝 加入生词本] ← 点击这个按钮
```

#### 3. 评估掌握程度

点击"加入生词本"后，会弹出评估界面：

```
┌─────────────────────────┐
│   procrastinate        │
│   拖延、耽搁            │
│                        │
│ 你掌握这个单词吗？      │
│                        │
│ [😰 不认识]            │
│ [🤔 有点模糊]          │
│ [✅ 基本掌握]          │
└─────────────────────────┘
```

- **不认识**: 从零开始学习，复习间隔较短
- **有点模糊**: 已有印象，中等复习间隔
- **基本掌握**: 基本记住，较长复习间隔

#### 4. 每日复习

1. 打开应用主页
2. 查看"今日待复习"数量
3. 点击"开始复习"
4. 逐个复习单词，评估记忆情况

#### 5. 查看进度

在统计页面可以看到：
- 总单词数
- 今日待复习
- 已掌握数量
- 学习中数量
- 掌握程度分布

## 📚 功能详解

### 艾宾浩斯记忆曲线

应用采用科学的间隔重复算法：

```
第 1 次复习: 1 天后
第 2 次复习: 2 天后
第 3 次复习: 4 天后
第 4 次复习: 7 天后
第 5 次复习: 15 天后
第 6 次复习: 30 天后
第 7 次复习: 60 天后
```

### 掌握等级系统

- **等级 0** (灰色): 完全陌生
- **等级 1** (红色): 刚接触
- **等级 2** (橙色): 有些印象
- **等级 3** (黄色): 基本认识
- **等级 4** (蓝色): 比较熟悉
- **等级 5** (绿色): 完全掌握

### 复习策略

根据你的评分，系统会自动调整：

| 评分 | 掌握程度变化 | 下次间隔 |
|------|------------|----------|
| 😰 不认识 | 降低 1 级 | 缩短 |
| 🤔 模糊 | 保持 | 不变 |
| ✅ 掌握 | 提升 1 级 | 延长 |

## 💡 使用技巧

### 1. 养成每日复习习惯

- 设置固定的复习时间（如：早上 9 点）
- 完成当天的所有复习任务
- 坚持至少 21 天形成习惯

### 2. 充分利用上下文

- 记录翻译时的完整句子
- 通过上下文理解单词含义
- 关联记忆更牢固

### 3. 诚实评估自己

- 不要过高估计自己的掌握程度
- "模糊"是正常的学习状态
- 多次复习才能真正掌握

### 4. 合理安排学习量

建议每天学习量：
- 新单词: 10-20 个
- 复习单词: 30-50 个
- 总计不超过 100 个

### 5. 配合其他学习方式

- 在阅读中遇到学过的单词
- 尝试在写作中使用
- 与他人交流时运用

## ❓ 常见问题

### Q1: 如何删除不想学的单词？

在生词本页面，每个单词卡片右上角有删除按钮。

### Q2: 可以修改单词的掌握程度吗？

每次复习时都可以重新评估，系统会自动调整等级。

### Q3: 错过了复习时间怎么办？

没关系，这些单词会一直保留在待复习列表中，下次复习时一起完成。

### Q4: 可以导出我的学习数据吗？

目前暂不支持，未来版本会添加导出功能。

### Q5: 支持其他语言吗？

目前主要支持英语学习，未来会考虑添加其他语言。

## 📈 学习建议

### 初学者 (单词量 < 100)

- 每天添加 5-10 个新单词
- 确保每天完成所有复习
- 重点关注高频词汇

### 进阶者 (单词量 100-500)

- 每天添加 10-15 个新单词
- 定期复习等级 3-4 的单词
- 扩展词汇到专业领域

### 高级者 (单词量 > 500)

- 根据阅读和工作需要添加
- 重点复习低频但重要的词汇
- 注意词汇的实际应用
